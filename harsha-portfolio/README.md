# Harsha Viroshan — Portfolio

A responsive Next.js portfolio starter with a dark futuristic visual system, purple/cyan accents, animated orbital hero, project showcase, creative gallery, skills, contact section, light-mode toggle, and a small Easter egg.

## Run locally on Windows 11
1. Install Node.js LTS from https://nodejs.org/ if you don't already have it.
2. Extract this folder.
3. Open the folder in VS Code, then open Terminal.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local address printed in the terminal (usually http://localhost:3000).

## Before publishing
- Replace the portrait placeholder with your photo (put it in `public/` and update `app/page.jsx`).
- Replace the example project descriptions and artwork with your real projects and editing work.
- Replace the generic LinkedIn, GitHub, and Instagram links with your profile URLs.
- In `app/page.jsx`, replace `YOUR_EMAIL@example.com` with the email address you want to receive enquiries at. The contact form opens a pre-filled email draft; it does not send messages through a server.
- Add real certificate/achievement details when ready. The achievement section can be added once you share which awards/certificates you want listed.

## Deploy to Vercel
1. Create a GitHub repository and upload the project files.
2. Sign in to https://vercel.com/ and import that repository.
3. Keep the default Next.js settings and click Deploy.

The site uses placeholder content intentionally: it avoids inventing personal achievements or linking to accounts that haven't been supplied yet.
